# Yamtrack – Home Assistant add-on

Runs [Yamtrack](https://github.com/FuzzyGrim/Yamtrack) on HAOS / Supervised installs.
Wraps the official image and bundles the Redis it needs.

## Install

1. In Home Assistant: **Settings → Add-ons (Apps) → Add-on Store → ⋮ → Repositories**
2. Add this repository's URL.
3. Install **Yamtrack**, set the `urls` option, start it.
4. Open the Web UI on port 8000 and create your account.
